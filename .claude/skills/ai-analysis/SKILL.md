# AI Analysis

Read-only natural-language assistant over the library (`/tools/ai`, `src/lib/ai/`), configured in Settings → AI (`AppSettings.aiEnabled/aiProvider/aiBaseUrl/aiApiKey/aiModel`).

- **Provider-neutral, no SDK**: `provider.ts` is a thin axios client for `openai-compatible` (OpenAI, Ollama, LM Studio, OpenRouter, Groq, vLLM, LocalAI, …) and native `anthropic`. `aiBaseUrl` is admin-set (no SSRF block — local models live on private IPs).
- **Safety model**: the model can call only the fixed read-only tools in `tools.ts` (no mutating tools); tools declare JSON-Schema `parameters` and each handler checks and clamps its args itself (never model-written SQL); they delegate to `src/lib/media/*` + `executeQuery`, inheriting scoping (`executeQuery` never dedups, so `search_media` collapses rows by `dedupKey` itself when dedup is on). `search_media` excludes Arr/Seerr fields (vacuous-match hazard). The system prompt treats tool-result text as data.
- **Grounding**: `system-prompt.ts` is built from the field/dimension registries and forbids inventing numbers; scope is the user's library and watch history only.
- **Orchestration**: `analyst.ts` runs a bounded (≤ 6 iterations) tool-calling loop, streaming `status`/`tool` events via `progressStreamResponse`, returning `{ answer, evidence }`. Keep-alive heartbeats come from `progressStreamResponse` itself (shared by every NDJSON route). The chat stream lifetime is `CHAT_MAX_LIFETIME_MS` (`analyst.ts`: every turn to its own timeout + 5 min); the route's literal `maxDuration` must cover it (`tests/integration/ai/chat.test.ts`). Provider limits (`provider.ts`): `REQUEST_TIMEOUT_MS` 10 min per turn, `TEST_TIMEOUT_MS` 3 min, `MAX_TOKENS` 8192 with a one-time retry at `FALLBACK_MAX_TOKENS` 4096 when a 400 refuses the size (`postWithTokenCap`, kept for the client's lifetime); `stripThinking` drops inlined `<think>` blocks and everything before a bare `</think>`. `testConnection` sends a real turn with one tool (`TEST_TOOL`) and fails an empty answer. Model ids are passed verbatim (dots and `:tag` included). Routes: `GET/PUT /api/settings/ai` (key masked; PUT skips `MASKED_VALUE`; can't enable without a model), `POST /api/settings/ai/test` (rate-limited), `POST /api/ai/chat` (streaming, `aiRateLimiter`, requires enabled + configured). `config.ts` resolves the config.
