Every endpoint of the [public API](/docs/advanced/api/), generated from the code these docs were built from. To try a request against your own Librariarr, set the server's **baseUrl** to its address, click **Authorize** and paste an [API key](/docs/advanced/api/#creating-an-api-key); nothing you enter is stored. The same document is served by your instance at `GET /api/v1/openapi.json` and downloadable under **Settings → Authentication → API Keys**.

Your Librariarr has to allow the browser's request: it sends no CORS headers, so **Try it out** works from here only when your reverse proxy adds them — otherwise use the **API docs** page inside Librariarr, which has no such limit.
