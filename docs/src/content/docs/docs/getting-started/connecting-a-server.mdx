## Adding a Server

<Steps>

1. **Navigate to Settings → Servers**

   Click the **Add Server** menu and choose **Plex**, **Jellyfin**, or **Emby**.

   For **Plex**, Librariarr opens the server picker (the same one as the
   [onboarding flow](#onboarding-flow)), which lists the servers on your Plex
   account. If no Plex account is linked yet, you are asked to sign in with
   Plex first.

2. **Enter connection details** (Jellyfin and Emby)

   - **URL**: The base URL of your server, including `http://` or `https://` (e.g., `http://192.168.1.100:8096`)
   - **API Key**: An API key from your server's dashboard (see below)
   - **Skip TLS verification**: Enable if your server uses a self-signed or untrusted certificate. For a certificate signed by your own CA, set [`NODE_EXTRA_CA_CERTS`](/docs/getting-started/installation/#environment-variables) instead

3. **Test the connection**

   Click **Test**. **Add Server** is enabled only after a successful test.

4. **Select libraries**

   After **Add Server**, choose which libraries to sync in **Select Libraries to Sync**. Each library can be independently enabled or disabled.

5. **Confirm and sync**

   Click **Confirm & Sync** to save the selection and start the first sync.

</Steps>

### Getting Your Access Token

#### Jellyfin

1. Go to **Dashboard → API Keys** in Jellyfin
2. Create a new API key for Librariarr

#### Emby

1. Go to **Server → API Keys** in Emby
2. Create a new API key for Librariarr

<Aside>
  Plex does not require a manual access token. Librariarr uses Plex OAuth to authenticate and automatically discovers your servers.
</Aside>

## Onboarding Flow

If this is your first time logging in and no servers are configured, Librariarr will guide you through an onboarding flow:

1. **Connect a Media Server** — Choose **Plex**, **Jellyfin**, or **Emby** (or *Skip for now*). Choosing Plex without a linked Plex account opens Plex sign-in first
2. **Plex server discovery** — Your Plex servers are listed with their name, platform, version, and known addresses
3. **Connection customization** — Choose or edit the connection URL for each server, and enable **Skip TLS Verification** if needed. Jellyfin and Emby take a URL and API key, tested before the server is added
4. **Library selection** — Pick which libraries to sync, then confirm to start the first sync
5. **Continue to Dashboard** — Once at least one server is added, you're taken to the dashboard

## Editing a Server

Click **Edit** on a server in **Settings → Servers** to change its URL, external URL, API key, or TLS setting. Changing the URL, or turning **Skip TLS verification** on, while keeping the stored token or API key needs a sign-in from the last 15 minutes; if it has been longer, Librariarr asks you to confirm it's you first. This stops a stolen browser session from sending the server's admin token to an address of its choosing.

## Library Management

### Enabling and Disabling Libraries

Each library can be toggled on or off in **Settings → Servers**. Only enabled libraries are synced.

<Aside type="caution">
  When you disable a library, you'll be asked whether to keep or delete that library's synced media data from the database (no media files are touched). The prompt also warns you when it is the last enabled library of its type.
</Aside>

### Refreshing Libraries

Click **Refresh** next to a server's library list to fetch the latest library list. New libraries are added automatically and can be enabled for syncing.

## Sync Behavior

### What Gets Synced

For each media item, Librariarr syncs:

- **Metadata**: title, year, rating, studio, genres, content rating, duration, play count, last played date
- **Video details**: resolution, format, frame rate, HDR type, and more
- **Audio details**: format, channels, quality, and languages
- **Subtitles**: languages and settings
- **File info**: size, format, and location
- **External IDs**: TMDB, TVDB, and IMDB (used to match with Sonarr, Radarr, and Lidarr)

### Multi-Server Deduplication

When the same media exists on multiple servers, Librariarr:

1. Identifies duplicates by external ID where available (TMDB or IMDB for movies, the series' TVDB ID plus season/episode for episodes), falling back to title and year, series title plus season/episode, or artist plus track title
2. Picks one copy as the **preferred version** shown in the library
3. Tracks which servers have each item and at what quality

You can configure which server's title and artwork to prefer in **Settings → General**.

### Sync Performance

- Only one sync runs per server at a time
- Progress is tracked and displayed in the Settings → Servers UI (% complete with item counts)
- Syncs can be triggered manually or run on schedule
