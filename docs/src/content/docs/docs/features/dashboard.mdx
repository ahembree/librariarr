The dashboard is the landing page after login — an operations console for your media libraries, organized into purpose-built zones from "what's happening right now" down to deep-dive charts.

![The dashboard with status strip, library overview tiles, and the lifecycle pipeline](/screenshots/dashboard.webp)

## Zones

### Status Strip

A compact row of live operational tiles at the top of the page. Each tile links to the page where you can act on it:

| Tile | Shows | Links to |
|-|-|-|
| Streams | Active playback session count; warns when a media server is unreachable | Tools → Streams |
| Sync | Whether a sync is running, when the last one finished, and the next scheduled sync | Settings → Scheduling |
| Integrations | How many Sonarr/Radarr/Lidarr/Seerr instances are reachable, naming any that are down | Settings → Integrations |
| Next runs | Countdown to the next lifecycle detection and execution runs | Settings → Scheduling |
| Update | Appears only when a newer Librariarr version is available | Settings → System |

Slow data sources (streams and integration health probe your servers) load in the background without blocking the rest of the page.

### Library Overview

One tile per media type — Movies, Series, Music — plus a Library Size total. Each type tile shows the item count, a **12-month additions sparkline** (hover it to see the exact count for each month), and size/runtime details, and clicks through to that library's browse page. The Library Size tile charts total size over the same window instead — hovering shows what your library size was at each month.

### Lifecycle Pipeline

The lifecycle system as a funnel, each stage linking to its page:

**Rule sets** (enabled count) → **Matches** (items currently matched) → **Pending actions** (scheduled work, with the next execution countdown) → **Reclaimed** (space freed by completed deletions).

If you haven't created any rule sets yet, this zone shows a shortcut to create your first one.

### Recently Added

A horizontally scrollable poster shelf of the newest additions across your libraries — 2:3 posters for movies and episodes, square album art for music — each with an added-time badge, hover details, and type/server filters.

Each entry shows the artwork of the thing that actually changed: an episode entry uses its **season** poster (falling back to the series poster when a season has none), and a music entry uses the **album** cover rather than an artist photo.

The shelf **updates on its own** as media is added or removed: it listens for sync events, so adding a file to your server surfaces it without reloading the page. With [real-time sync](/docs/features/real-time-sync/) enabled that is usually within a second or two of your server noticing.

Additions are grouped into the unit you actually added, rather than one tile per file:

- **Episodes** collapse per season — a season pack, or this week's episode, reads as one entry naming the season and how many episodes arrived, instead of one identical poster per episode. Two seasons of the same show stay separate, and two different shows that happen to share a title stay separate too (grouping keys on the series' TVDB/TMDB identity, not its name).
- **Tracks** collapse per album, showing the album title over the artist.
- **Movies** are never grouped.

Clicking a grouped tile opens that season or album; clicking a single item opens the item. Grouped tiles have no hover card — one episode's file size and resolution shouldn't be presented as the whole season's.

### Insights

A fully customizable chart grid — this is the only zone with a layout editor. Click **Customize** to rearrange, resize, remove, or add cards. Your layout is saved automatically and persists across sessions.

![The Recently Added shelf and the Insights grid with a quality breakdown card](/screenshots/insights.webp)

Distribution cards share one design: per-type proportion strips (or a donut with the total in its center) above ranked value rows whose background fill shows each value's share. Click a row to exclude that value from the totals; hover a row for its per-type split. Top Played cards show artwork thumbnails for each entry.

#### Built-in Cards

| Card | Description |
|-|-|
| Quality Breakdown | Resolution distribution across your library |
| Video Codec | Video codec distribution (H.264, HEVC, etc.) |
| Audio Codec | Audio codec distribution (AAC, AC3, etc.) |
| Content Rating | Content rating distribution (PG, R, TV-MA, etc.) |
| Top Played | Most played movies, series, and music |
| Dynamic Range | HDR format distribution (Dolby Vision, HDR10, SDR, etc.) |
| Audio Channels | Surround sound layout distribution (Stereo, 5.1, 7.1, etc.) |
| Genre Breakdown | Genre distribution across your library |
| Seerr Requests | Top requesters and watch follow-through |

The **media type filter** above the grid scopes every chart to Movies, Series, or Music.

#### Custom Cards

Custom cards let you create charts with any dimension and chart type. Click **Customize → Add Card → Custom Card**.

##### Chart Types

| Type | Description |
|-|-|
| Bar | Vertical bar chart |
| Pie | Donut chart |
| Line | Line chart |
| Area | Filled area chart |
| Radar | Spider/radar chart |
| Treemap | Proportional rectangle grid |
| Heatmap | Two-dimension correlation grid (requires two dimensions) |
| Count | Large single number |
| Timeline | Time-series chart with zoom slider; pick a date field for the X-axis, an optional breakdown dimension for colored series, and a time interval (day, week, month, quarter, year) |

##### Available Dimensions

Custom cards can visualize data across many dimensions, grouped by category:

- **Video** — Resolution, Video Codec, Dynamic Range, Video Profile, Frame Rate, Bit Depth, Scan Type, Aspect Ratio, Video Bitrate
- **Audio** — Audio Codec, Audio Channels, Audio Profile, Sampling Rate, Audio Bitrate
- **Streams** — Audio Language, Subtitle Language
- **Content** — Content Rating, Genre, Year, Studio, Countries
- **File** — Container, File Size, Duration
- **Dates** — Added Date, Last Played, Release Date
- **Engagement** — Critic Rating, Audience Rating, Play Count

## Server Filter

When multiple servers are connected, the server selector in the page header scopes the library tiles, sparklines, recently added, and insight charts to a single server.

## Multi-Server Statistics

When multiple servers are connected, the **Deduplicate stats across servers** setting in **Settings → General** controls how items are counted:

- **On**: Media that exists on multiple servers is counted once
- **Off**: Every copy on every server is counted separately

<Aside>
  This setting only affects dashboard counts. Library browsing always deduplicates by default.
</Aside>
